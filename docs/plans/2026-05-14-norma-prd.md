# Norma - 本地桌面端人格化智能体 PRD

## 1. 产品愿景与定位
Norma 是一个基于本地环境深度集成的“人格化智能体”与“超级代理”。它不仅仅是一个聊天的 UI，更是一个能够感知操作系统状态、操控本地应用、通过自我反思解决复杂任务的数字助手。它依托 Mastra 强大的 Agent 编排能力和 Electron 的底层访问权限，旨在成为高阶知识工作者的桌面生产力中枢。

## 2. 核心界面形态：渐进式双模态 (Progressive Dual-Mode UI)

Norma 采用混合形态，以适应不同场景的效率需求：

*   **Mode A：沉浸式主窗口 (Primary Hub)**
    *   **定位：** 复杂任务编排、多轮深度对话、结果展示的中心。
    *   **设计：** 类似 Claude/ChatGPT 的独立桌面窗口。
    *   **特性：** 包含完整的对话流、丰富的 Markdown/代码块渲染。最重要的是，主窗口内置了“**多智能体群聊视图**”。默认情况下，Norma（Router Agent）隐式分发任务，界面保持清爽；但用户可展开“思考面板(Thinking Panel)”查看后台 SubAgent（如 `CoderAgent`, `WebSearchAgent`）的通信流转和执行日志。高级用户亦可在输入框使用 `@` 显式唤醒特定 SubAgent 介入对话。

*   **Mode B：全局唤出命令栏 (Command Bar)**
    *   **定位：** 用完即走、高频轻量级任务、快捷工作流入口。
    *   **设计：** 类似 Raycast / Spotlight，通过全局快捷键（如 `Cmd/Ctrl + Space` 的变体）唤起，居中悬浮于当前桌面。
    *   **特性：** 聚焦于快速输入短指令、快速调用特定技能（如“总结当前选中文字”、“截屏并翻译”）。执行完毕后自动隐藏，将结果输出到剪贴板或后台通知，或者根据需要平滑展开为主窗口 (Mode A)。

## 3. 执行能力双引擎 (Execution Dual-Engine)

为了实现对本地环境的全面掌控，Norma 在能力层采用“双引擎”架构，兼顾了兜底的鲁棒性和生态的扩展性。

*   **引擎 A：兜底“核武器” (Native Core)**
    *   **定位：** 万能感知与强制操控，处理没有现成 API 的长尾场景和封闭应用。
    *   **实现机制：** 直接利用 Node.js / Electron 的原生能力结合底层自动化库 (如 `robotjs` 等)。
    *   **感知能力：** 全局/区域屏幕截图抓取、剪贴板监控、基于本地小模型的快速 OCR/CV (计算机视觉) 分析屏幕元素坐标。
    *   **操控能力：** 基于坐标轴的绝对模拟鼠标移动、点击、拖拽，以及全局物理键盘事件模拟。这使得 Norma 可以“看见”屏幕并像真人一样“操作”任何软件。

*   **引擎 B：MCP 扩展生态 (MCP Protocol)**
    *   **定位：** 结构化数据交互、精准 API 调用、拥抱开源 Agent 生态。
    *   **实现机制：** 完全实现并兼容 Model Context Protocol (MCP)。
    *   **特性：** 用户可通过配置轻松接入市面上现有的 MCP Servers (例如 GitHub MCP, Notion MCP, Local FileSystem MCP, PostgreSQL MCP 等)。当面对有清晰 API 和结构化数据的任务时，Norma 会优先使用 MCP 获得极高的准确率和效率，将“核武器”留作无 API 时的最终后备。

## 4. 记忆与自适应学习层 (Memory & Self-Healing Layer)

Norma 不是一次性的脚本执行器，而是能够沉淀经验的系统。

*   **用户偏好记忆 (Semantic Memory)：**
    *   后台持续运行一个“记忆整理器 (Memory Consolidation Agent)”。
    *   从日常对话中提取事实、偏好、习惯（例：“用户在处理 Python 项目时习惯用 pytest”）。
    *   将这些知识转化为向量 Embedding 存入本地数据库 (如 SQLite + 本地 Vector 扩展)，在后续对话中作为隐式 Context 注入。

*   **执行自愈与反思 (Self-Healing Loop)：**
    *   **闭环执行：** 当 Norma 执行复杂本地脚本或命令流时，它会捕获标准输出 (stdout) 和标准错误 (stderr)。
    *   **反思修正：** 一旦检测到执行失败或报错，Norma 会进入自愈循环。它会将报错信息作为输入，调用内部的反思 Prompt 重新思考原因，动态修改脚本或调整重试策略，并再次尝试执行。
    *   **经验固化：** 当自愈成功后，Norma 会将“遇到 X 错误 -> 原理是 Y -> 解决策略是 Z”这段经验进行总结，更新到本地的“技能经验库”中，避免下次踩同样的坑。

## 5. Agent 架构与工作流编排 (Mastra Core)

*   **中枢路由 (Router Agent):** 系统的入口，负责理解用户意图，判断是直接回答、调用工具，还是分发给专业 SubAgent。
*   **SubAgent 生态:** 基于 Mastra 构建专门领域的 Agent (例如专门写代码的 `DevAgent`，专门查文档的 `ResearchAgent`，专门处理 GUI 自动化的 `ActionAgent`)。
*   **工作流 (Workflows):** 对于固定的复杂流程（如：每天早上读取未读邮件 -> 总结要点 -> 生成待办事项），通过 Mastra 的 Workflow API 进行硬编码或动态组装编排。

## 6. 技术选型与约束

| 组件 | 选型 | 备注说明 |
| :--- | :--- | :--- |
| 基座 | Node.js 24+ LTS | 提供最新的原生能力支持 |
| 语言 | TypeScript | 保证强类型和大型项目可维护性 |
| 桌面 | Electron 42+ | 跨平台应用外壳，提供系统级 API |
| 包管理 | PNPM | 高效依赖管理 |
| JSON校验 | Zod | 严谨的 Agent 工具参数校验与 API 边界防护 |
| 智能体框架 | Mastra | 核心 Agent 编排与 Workflow 管理引擎 |
| UI框架 | AssistantUI | 构建聊天界面的基础层，支持定制主题和组件 |
| 技能标准 | AgentSkills | 作为定义和分发原子能力的规范 |
| 本地数据 | SQLite | 本地轻量级关系型数据存储 (包含 Vector 插件以支持记忆搜索) |
